# PRD: Charm UI 第一阶段优化

## Problem Statement

当前 Nginx 日志分析工具的输出是纯文本表格，视觉效果不够直观美观；命令行帮助信息比较简单，缺少实用示例。用户希望通过引入现代 Go CLI 库来提升用户体验。

## Solution

使用 Charm 全家桶（lipgloss）美化 stats 命令的输出，添加颜色、边框和 ASCII 条形图；同时改进 Cobra 命令的帮助信息和示例，让工具更易上手。

## User Stories

1. 作为一个运维工程师，我想看到带颜色的状态码分布（2xx绿色、3xx黄色、4xx橙色、5xx红色），以便快速识别问题
2. 作为一个开发者，我想看状态码分布的 ASCII 条形图，以便更直观地理解数据比例
3. 作为一个工具使用者，我想看到美观的表格边框和排版，以便提升使用体验
4. 作为一个新用户，我想在 `--help` 中看到详细的使用示例，以便快速上手
5. 作为一个新用户，我想看到每个子命令的具体示例，以便了解如何使用各种过滤选项
6. 作为一个工具使用者，我想看到总请求数有醒目的显示，以便第一眼获取关键信息
7. 作为一个运维工程师，我想 Top 10 IP/URL/User-Agent 的表格有更好的视觉层次，以便快速阅读
8. 作为一个工具使用者，我想保持现有功能完全不变，只优化输出效果，以便不破坏现有工作流

## Implementation Decisions

### 模块修改

1. **analyzer 模块**：重写 `PrintStats` 函数，使用 lipgloss 构建美化后的输出
2. **main 模块**：改进所有 Cobra 命令的 `Short`、`Long` 描述和 `Example` 示例
3. **新增 ui 模块**（可选）：如果样式逻辑较复杂，可以提取独立的 ui 模块封装 lipgloss 样式

### 技术决策

- 使用 `github.com/charmbracelet/lipgloss` 进行样式渲染
- 使用 `github.com/charmbracelet/bubbles/table` 或手写 lipgloss 表格（看哪个更简单）
- 保持现有 `StatsResult` 数据结构完全不变
- 保持所有公开函数接口不变
- 颜色方案：2xx=绿色、3xx=黄色、4xx=橙色、5xx=红色
- ASCII 条形图使用方块字符（如 █）实现，按比例显示

### 输出结构

美化后的 stats 输出大致结构：
1. 醒目的总请求数卡片
2. 状态码分类表格 + ASCII 条形图
3. Top 10 IP 表格
4. Top 10 URL 表格
5. Top 10 User-Agent 表格

### 帮助信息改进

- 每个命令添加 `Example` 字段，包含常用场景示例
- `Long` 描述更详细地说明功能
- filter 命令的每个 flag 说明更清晰，包含格式示例

## Testing Decisions

- 测试只验证**外部行为**：输出包含预期的关键信息（总请求数、状态码分布等），不测试具体样式字符
- 保持现有测试不变（如果有），新增测试验证输出包含关键数据
- 可以手动验证视觉效果，因为样式是主观的

### 现有测试参考

项目已有 parser 和 filter 的单元测试，测试风格是通过公共 API 验证行为，而非实现细节。新测试遵循同样风格。

## Out of Scope

- filter 命令输出美化（第二阶段）
- 进度条/Spinner（第二阶段）
- 自动检测日志格式（第三阶段）
- 用 gonx 替换正则解析（第三阶段）
- 配置文件支持
- TUI 交互模式
- 结构化日志改进

## Further Notes

这是第一阶段优化，优先解决最核心的用户体验问题。后续阶段可以继续完善其他功能。保持渐进式迭代，每阶段都有可交付的价值。
