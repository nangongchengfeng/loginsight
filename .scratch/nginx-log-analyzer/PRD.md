# PRD: Nginx 日志分析 CLI 工具

## Problem Statement

刚学完 Go 语言，需要通过做项目来加深对 Go 的学习和理解。需要一个有实际价值、能覆盖 Go 核心知识点（文件 I/O、字符串处理、数据结构、时间处理、CLI 开发）的项目。

## Solution

开发一个基于 Cobra 的 Nginx 日志分析 CLI 工具，支持日志统计和过滤查询。从简单场景切入（只支持 Nginx combined 格式），先跑通核心功能再重构，通过实践学习 Go。

## User Stories

1. 作为 Go 学习者，我想解析 Nginx combined 格式日志，以便学习文件读取和字符串处理
2. 作为 Go 学习者，我想用 map 聚合统计数据，以便学习 Go 的数据结构
3. 作为 Go 学习者，我想实现排序功能，以便学习 sort 包
4. 作为 Go 学习者，我想用 Cobra 构建 CLI，以便学习 Go 的 CLI 开发
5. 作为工具使用者，我想看总请求数统计，以便快速了解日志规模
6. 作为工具使用者，我想看状态码分布（2xx/3xx/4xx/5xx），以便了解服务健康状况
7. 作为工具使用者，我想看 Top 10 IP，以便识别高频访问者
8. 作为工具使用者，我想看 Top 10 URL，以便识别热门资源
9. 作为工具使用者，我想看 Top 10 User-Agent，以便了解客户端分布
10. 作为工具使用者，我想按状态码过滤日志，以便只看错误请求
11. 作为工具使用者，我想按 IP 过滤日志，以便追踪特定客户端
12. 作为工具使用者，我想按请求路径过滤日志，以便分析特定接口
13. 作为工具使用者，我想按 HTTP 方法过滤日志，以便只看 GET/POST 等
14. 作为工具使用者，我想按时间范围过滤日志，以便分析特定时段
15. 作为工具使用者，我想生成样本 Nginx 日志，以便在没有真实日志时测试
16. 作为 Go 学习者，我想先把代码写在 main.go 里跑通，以便快速验证想法
17. 作为 Go 学习者，我想之后重构拆分模块，以便学习 Go 的项目组织

## Implementation Decisions

- **日志格式：** 只支持 Nginx combined 格式，硬编码解析逻辑
- **CLI 结构：** 使用 Cobra 子命令：`stats`（统计）、`filter`（过滤）、`gen-sample`（生成样本）
- **依赖：** 只使用 Go 标准库 + Cobra，不引入其他第三方库
- **开发阶段：** 分两阶段
  - 第一阶段：极简结构，所有逻辑放 main.go，跑通核心功能
  - 第二阶段：重构，拆分为 Parser、Analyzer、Filter 模块
- **统计输出：** 使用 text/tabwriter 格式化表格输出
- **过滤条件：** 支持 --status、--ip、--path、--method、--since、--until
- **时间格式：** 只支持绝对时间，格式为 2006-01-02T15:04:05Z07:00
- **样本生成：** 生成 realistic-looking 的 Nginx 日志，包含随机 IP、路径、状态码等

## Testing Decisions

- **测试策略：** 第一阶段使用样本生成器手动测试；第二阶段补充单元测试
- **测试模块：** Parser、Analyzer、Filter 模块需要单元测试
- **测试原则：** 测试外部行为而不是实现细节，比如给定日志行验证解析结果，给定日志列表验证统计结果

## Out of Scope

- 支持其他日志格式（Apache、JSON、syslog 等）
- 相对时间解析（1h、2d 等）
- 复杂过滤逻辑（AND/OR 组合）
- 可视化图表输出
- JSON/CSV 报告导出
- 配置文件支持

## Further Notes

- 这是一个学习项目，代码清晰度和可理解性优先于极致性能
- 重构时保持功能不变，只调整代码组织
- 每完成一个功能就提交一次，便于回溯学习过程
